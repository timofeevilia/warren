# 04 · «Ателье»: часы, которых нет

Запись журнала разработки. Рабочий материал для статей.

## Что получилось

Страница `/atelier/`: сайт вымышленной часовой мастерской Atelier Lièvre и её единственной
модели Terrier 38. Часы нарисованы кодом, показывают настоящее время посетителя, поворачиваются
и переворачиваются. Внизу страницы конфигуратор: корпус, циферблат, стрелки, усложнение,
ремешок, размер, гравировка на задней крышке.

Название обыгрывает общую тему: lièvre по-французски «заяц», terrier — «нора».
В подвале страницы прямо сказано, что мастерская вымышлена и ничего не продаётся.

По проекту в целом после четырёх экспериментов: вся сборка 840 КБ, исходный код около
7 600 строк, изображений в сборке одно (маска суши для «Пульса», 37 КБ).

## Решение 1. Часы — это SVG, а не 3D-модель

Трёхмерный движок здесь не нужен. Часы — два рисунка SVG, лицо и оборот, которые стоят
спина к спине в трёхмерном пространстве CSS.

- **Поворот и переворот** делает `rotateY` с `backface-visibility: hidden`: когда часы
  развёрнуты, видна задняя крышка.
- **Толщина корпуса** — семь дисков между лицом и оборотом, сдвинутых по оси Z на 2 пикселя.
  При наклоне они складываются в боковую стенку.
- **Металл** — линейные градиенты из четырёх точек: блик, середина, тень, свет по краю. Смена
  материала корпуса меняет четыре цвета, всё остальное перерисовывается само.
- **Солнечная шлифовка циферблата** — 48 клиньев с чередующейся прозрачностью.
- **Сапфировое стекло** — блик, который сдвигается при наклоне.

Положение часов для каждого раздела страницы — это четыре числа: масштаб, два угла, сдвиг.
Переход между положениями делает одна строка CSS `transition`.

## Решение 2. Часы идут по-настоящему

- Стрелки показывают время на устройстве посетителя.
- Секундная стрелка движется не плавно и не раз в секунду, а восемью шагами в секунду. Так
  ведёт себя механизм с частотой 28 800 полуколебаний в час, заявленной в характеристиках.
- На обороте за сапфировым окном видно механизм: баланс качается четыре раза в секунду, колёса
  вращаются с разной скоростью, ротор автоподзавода медленно проворачивается и откликается на
  движение курсора.
- В окошке даты сегодняшнее число.

Здесь хорошо видно, зачем Solid. Рисунок сложный, но каждый кадр меняется около десятка
значений: углы стрелок, колёс и баланса. Каждое привязано к своему сигналу, и за кадр
переписывается только десяток атрибутов `transform`. Остальные сотни элементов SVG не трогаются.

## Решение 3. Три острова и одно состояние

На странице три независимых приложения:

1. **Часы** (Solid) — закреплены справа, читают конфигурацию и позу.
2. **История** (Svelte) — текст слева: заголовок, главы, характеристики.
3. **Конфигуратор** (Solid) — в потоке страницы под историей.

Общее состояние — два хранилища в `src/lib/atelier/catalog.ts`:

- `config` — какие часы собраны;
- `view` — как они стоят.

Данные текут во все стороны. Конфигуратор (Solid) меняет `config`, и цена в шапке (Svelte)
обновляется. В главе «Четыре металла» кнопки внутри текста Svelte меняют корпус, и часы на
Solid перекрашиваются. Глава, оказавшаяся в центре экрана, ставит часам позу. Фокус в поле
гравировки переворачивает часы оборотом, чтобы надпись появлялась на крышке по мере набора.

Два острова на Solid тоже не знают друг о друге: они общаются через то же хранилище, что и со
Svelte. Механизм один на все случаи.

## Решение 4. Ссылка — это часы

Конфигурация записывается в адрес страницы: `#c=gold.salmon.leaf.seconds.bracelet.40`.
Адрес обновляется при каждом изменении без записей в истории браузера. Если открыть такую
ссылку, часы восстанавливаются, включая гравировку.

Сервера и базы данных для этого не нужно. Проверка входных данных всё равно есть: неизвестные
значения заменяются на стандартные, длина гравировки ограничена 22 символами, испорченная
кодировка просто теряет гравировку.

## Решение 5. Светлая тема одной заменой токенов

Остальной сайт тёмный, эта страница светлая, цвета тёплой бумаги. Тема сделана так: у тега
`html` появляется класс `theme-paper`, и восемь цветовых токенов получают другие значения.
Ни один компонент не менялся: всё, что написано как `background: var(--color-bg-ink)`, стало
бумажным. Переходы между тёмными и светлой страницами работают без перезагрузки.

В Figma то же сделано параллельным набором переменных `paper/*`: тариф файла допускает только
один режим на коллекцию.

## Найденные по дороге ошибки

- **Размытые часы на экранах высокой плотности.** Браузер растрирует трёхмерный слой один раз
  в размере CSS и затем растягивает картинку. На телефоне с плотностью 3 и при увеличении
  циферблата часы выглядели мыльными. Решение: каждая грань верстается втрое крупнее и
  уменьшается обратно через `scale(1/3)`. В растре в девять раз больше пикселей, изображение
  резкое. То же сделано для дисков, образующих толщину корпуса.
- **На телефоне часы наезжали на опции.** Сцена с часами закреплена в верхней части экрана,
  а страница прокручивалась под ней без подложки. Добавлена полоса фона с растворением книзу.
- **Кнопка «Reserve» была серой вместо светлой:** правило прозрачности для подписи с артикулом
  захватывало и кнопки. Найдено по скриншоту.
- **Ссылка не применялась без перезагрузки.** Если вставить другую ссылку в ту же вкладку,
  меняется только часть адреса после решётки, и страница этого не замечала. Добавлен
  обработчик `hashchange`.

## Что проверено и что нет

Проверено в headless Chromium: страница без ошибок в консоли; все шесть поз часов; смена металла
из текста меняет часы и цену в шапке; конфигуратор считает цену верно (2 400 + 6 200 + 120 +
320 + 350 + 90 = 9 480); ссылка восстанавливает конфигурацию и гравировку в новой вкладке;
переход с витрины и обратно меняет тему; на размере iPhone 13 нет горизонтальной прокрутки;
резкость при плотности пикселей 2 и 3.

Не проверено: Safari (трёхмерные преобразования и фильтры SVG там ведут себя иначе, это главный
риск), Firefox, реальные телефоны, плавность поворота на слабых устройствах, чтение с экранным
диктором. Часы помечены как декоративные (`aria-hidden`), текстового описания конфигурации для
незрячих пока нет.
